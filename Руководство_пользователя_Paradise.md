# Руководство пользователя

**Информационная система «Paradise — электронная библиотека»**

---

## 1. Назначение

Paradise — приложение для ведения личной электронной библиотеки: учёт книг, чтение, сохранение прогресса, каталог с сервера. Для администратора — управление данными в БД, статистика и отчёты.

**Форматы:** TXT, MD, RTF, FB2, XML, PDF, EPUB.

---

## 2. Требования и запуск

| Компонент | Требование |
|-----------|------------|
| ОС | Windows 10/11 (64-bit) |
| Среда | .NET 9 для Windows |
| БД | MySQL (база проекта, обычно **Paradise**) |
| Экран | от 1280×720 |

1. Запустите исполняемый файл клиента.
2. Убедитесь, что MySQL запущен и база создана.
3. При необходимости загрузите книги утилитой **Loader** (раздел 8).

---

## 3. Авторизация

После загрузки отображается форма приветствия:

- **Вход** — логин и пароль.
- **Регистрация** — создание аккаунта.
- **Продолжить как гость** — работа без учётной записи (с ограничениями).

---

## 4. Интерфейс

**Боковая панель:** «Книги», «Каталог книг», для администратора — «Админ-панель»; внизу — «Настройки», «Помощь». Заголовок **Paradise** возвращает к основному экрану.

### 4.1. Книги

Список личной библиотеки, статистика, быстрые действия: добавить, читать, очистить список, отчёт, сброс прогресса.

### 4.2. Добавление и управление

**«Добавить книгу»** — выбор файла. В строке списка — чтение, правка, удаление; контекстное меню — дополнительные действия.

### 4.3. Чтение

**A+** / **A−** — шрифт; **←** / **→** — страницы; индикатор прогресса. **«Вернуться к библиотеке»** — назад к списку.

### 4.4. Каталог книг

Книги с сервера, поле **«Поиск»**, добавление в библиотеку с карточки.

### 4.5. Настройки

Тема, прозрачность, параметры чтения, интерфейс, файлы, уведомления, аккаунт, «О программе». Кнопки: сброс, экспорт, закрыть.

### 4.6. Админ-панель

Книги, файлы, пользователи, статистика, прогресс, отчёты, резервное копирование. В настройках — путь к папке **DB**.

---

## 5. Завершение работы

- **«Выход»** (верхняя панель) — закрытие приложения.
- Выход из аккаунта — в настройках, без закрытия программы.

---

## 6. Loader

Вспомогательное приложение для пакетной загрузки книг в MySQL. Используется администратором при подготовке стенда; обычному пользователю не требуется.

---

*Справка также доступна в приложении: кнопка **«Помощь»** на боковой панели.*
